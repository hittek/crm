# S02b: Org and Chatbot Lifecycle Hooks

**Goal:** Make Chatwoot provisioning happen on every org creation path (not just signup) and wire chatbot lifecycle to Chatwoot — create/update/delete synced to the Platform API
**Demo:** After this: create org via admin panel OR create chatbot in CRM → Chatwoot account+AgentBot auto-provisioned; chatbot update propagates webhook URL to AgentBot; all paths idempotent

## Must-Haves

- POST /api/admin/orgs (create) → Chatwoot account+AgentBot provisioned\n- POST /api/chatbot/bots → AgentBot webhook updated to route to that chatbot\n- PATCH/DELETE chatbot → AgentBot synced\n- All calls idempotent

## Proof Level

- This slice proves: integration — create org via admin panel and chatbot via API; verify Chatwoot reflects both

## Integration Closure

Every Organization row always has chatwootAccountId; every Chatbot row always has its AgentBot webhook up-to-date; idempotent on retry
