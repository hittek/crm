# S02: Multi-tenant Org Provisioning via Platform API

**Goal:** Wire up CRM org creation to auto-provision a Chatwoot account + AgentBot via the Platform API, storing the Chatwoot account ID and AgentBot webhook secret on the CRM Organization record
**Demo:** Create org in CRM → Chatwoot account + AgentBot auto-provisioned via Platform API.

## Must-Haves

- POST /api/organizations creates a CRM org AND a Chatwoot account in one transaction
- Organization row has chatwootAccountId set
- GET /platform/api/v1/accounts returns the new account
- Existing orgs can be backfilled via a script

## Proof Level

- This slice proves: integration — create a new org via CRM API and verify Chatwoot account appears in Platform API response

## Integration Closure

Organization.chatwootAccountId and Organization.chatwootAgentBotId populated on creation; CRM can call Chatwoot API on behalf of any org using the platform token
