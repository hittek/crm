# S03: AgentBot Bridge — Replace Raw Webhooks

**Goal:** Build POST /api/chatbot/agentbot/[slug] — receives Chatwoot AgentBot webhook, routes to Claude+RAG via processMessage, sends reply back to Chatwoot Conversations API
**Demo:** Send WhatsApp message → Claude+RAG responds — via Chatwoot AgentBot, zero raw Meta webhook code remaining

## Must-Haves

- POST /api/chatbot/agentbot/[slug] returns 200 for message_created events\n- Incoming user message routed to correct chatbot via ?botKey param\n- Claude+RAG reply sent to Chatwoot via account conversations API\n- escalated event → bot_handoff in Chatwoot\n- Non-message events (conversation_resolved etc.) return 200 silently\n- chatwootAgentBotToken stored on Organization for API auth

## Proof Level

- This slice proves: integration — send a test message in Chatwoot conversation; verify Claude response appears in Chatwoot

## Integration Closure

End-to-end message flow: Chatwoot inbox message → AgentBot webhook → CRM Claude+RAG → Chatwoot reply API → user sees response in Chatwoot UI
