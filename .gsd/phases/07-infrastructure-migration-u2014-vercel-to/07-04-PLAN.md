# S04: Custom Domain Migration (crm.hittek.mx)

**Goal:** Point crm.hittek.mx to the RPi4 app so Vercel is no longer in the request path.
**Demo:** https://crm.hittek.mx loads the app running on RPi4 — Vercel no longer in the request path

## Must-Haves

- https://crm.hittek.mx/api/health returns {status:ok} and the response comes from the RPi4 Docker stack, not Vercel.

## Proof Level

- This slice proves: manual — curl + response header check from an external network

## Integration Closure

DNS A/CNAME for crm.hittek.mx resolved to RPi4 (or ngrok CNAME), SSL terminates cleanly, app responds with correct origin headers.

## Verification

- None — no new instrumentation needed.
