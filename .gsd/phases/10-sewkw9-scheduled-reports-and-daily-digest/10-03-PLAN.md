# S03: Query executor and chart renderer

**Goal:** Query executor that translates the ReportDefinition DSL into Prisma calls and returns Recharts-compatible data, plus a run endpoint.
**Demo:** User opens /reports — sees the same dashboard as today but powered by the report engine. User clicks 'Personalizar' and drags a new bar chart onto the canvas.

## Must-Haves

- GET /api/reports/[id]/run returns widget data arrays. number_card returns { value, subvalue? }. bar/line/pie return [{ name, value }] arrays. groupBy queries produce correct grouped output. Time templates resolve correctly.

## Proof Level

- This slice proves: API + DB live data

## Integration Closure

executor.js imports prisma and base.js resolveTemplateValue. Run endpoint reads ReportDefinition from DB and passes definition JSON to executor.
