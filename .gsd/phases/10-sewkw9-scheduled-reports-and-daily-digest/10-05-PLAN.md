# S05: Email and push delivery on completion

**Goal:** Deliver completed report runs as an email digest (Resend) and a push notification to org users.
**Demo:** 8am: push notification 'Tu reporte está listo' arrives in browser. Email arrives: subject 'Reporte: Resumen diario — Hittek', body shows 3 KPI cards + View Report button.

## Must-Haves

- After a successful tick, org admin users receive a push notification. If RESEND_API_KEY is set, an HTML email is sent. Delivery gracefully skips when keys are absent. Delivery failures do not throw — they log and continue.

## Proof Level

- This slice proves: API response + logs (no real email in dev unless RESEND_API_KEY is set)

## Integration Closure

lib/deliverers/email.js and push.js are called from runScheduledReport in lib/scheduler.js after status=delivered. Email uses Resend SDK; push reuses existing sendPushToUser from lib/webpush.js.
