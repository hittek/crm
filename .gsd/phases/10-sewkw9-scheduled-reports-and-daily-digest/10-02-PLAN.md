# S02: Claude NLP report builder endpoint

**Goal:** Claude NLP builder: POST a plain-language prompt and receive a validated ReportDefinition JSON, optionally persisted.
**Demo:** POST /api/reports/build {prompt: 'negocios ganados por vendedor este mes'} → {definition: {widgets: [{type:'bar_chart', ...}]}} in under 5s with streaming status updates

## Must-Haves

- POST /api/reports/build with a plain-text prompt returns a valid parsed definition JSON. Invalid Claude output is caught and returned as a 422 with the raw text. Saved definitions appear in ReportDefinition table scoped to the org.

## Proof Level

- This slice proves: API + DB

## Integration Closure

Endpoint calls @anthropic-ai/sdk, validates with Zod, and writes to Prisma. Auth guard uses existing session middleware.
